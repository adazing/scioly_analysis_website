What is it?

This file describes all the available events to compete in at a competition and groups similar events.

Step 1: Make data. Requirements:

  • There is no header.
  • All available events must be mentioned once, and there must not be any repeats.
  • Each row corresponds to a group of events that are similar.
  • All events mentioned should have the same name as the event names you used for your past invitational data.
  • Each row is assumed to end as soon as it reaches an empty cell. Therefore, all events on each row should be stated in the first cell and leave no blank cells between until the end is reached.
  • Any event with three members (default is two) should be indicated as such with a "(3)" next to the name.
  • Any build event should be indicated as such with a "(B)" next to the name.
  • There should be no other information in the sheet.


Step 2: Download CSV data.
File -> Download -> Comma Separated Values (.csv)

What is it?

This file describes any events that might conflict at a competition (so no member can do two conflicting events at the same time).

Step 1: Make data. Requirements:

  • There is no header.
  • Not all events need to be mentioned, but there should be no repeats of the mentioned events.
  • Each row corresponds to a group of events that are in the same timeblock. Therefore, no one can do both of the events at the same time.
  • Each row is assumed to end as soon as it reaches an empty cell. Therefore, all events on each row should be stated in the first cell and leave no blank cells between until the end is reached.
  • There is no limit to row length or row number.
  • There should be no other information in the sheet.


Step 2: Download CSV data.
File -> Download -> Comma Separated Values (.csv)

What is it?

This file describes the available members able to compete in the upcoming competition and their top event preferences. If there are no events inputted, then the program just treats the file as an attendance list.

Step 1: Make data. Requirements:

  • All members that want to be on the competition should be present with no repeats.
  • If a member is a senior (max 7 seniors allowed on each team), place an "(S)" tag next to their name
  • There is no header.
  • All members must be stated in the A column and should be strings. Only letters will be taken into account. Uppercase/lowercase does not matter. Make sure that the way you named the member is the same as in all past invitational data.
  • Each member may have a list of preferences that are ranked. There is no specific number of events they must rank, and it can change with each member. Alternatively, each member can have no ranked preferences, meaning the teams are decided solely on skill level. The event names should be stated as strings, and only letters will be taken into account. Uppercase/lowercase does not matter. Make sure that the way you named the event is the same as in all the other data.
  • The events do not need to be in any order, and there is no max number of events.
  • Colors/formatting does not matter.
  • There should be no other data in the file except that of which is explained above.


Step 2: Download CSV data.
File -> Download -> Comma Separated Values (.csv)

What is it?

This file describes any preferences where two members want to be on the same event together.

Step 1: Make data. Requirements:

  • Not all members that want to be on the competition need to be mentioned and there can be repeats of member names.
  • There is no header.
  • All members must be stated in the A and B columns and should be strings. Only letters will be taken into account. Uppercase/lowercase does not matter. Make sure that the way you named the nenber is the same as in all the other data.
  • Cells in column C can hold the preferred event that both members in the row want to be in. An empty event cell means that both members don't care about the particular event they would be put into. The event names should be stated as strings, and only letters will be taken into account. Uppercase/lowercase does not matter. Make sure that the way you named the event is the same as in all the other data.
  • Colors/formatting does not matter.
  • There should be no other data in the file except that of which is explained above.
