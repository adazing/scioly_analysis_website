All CSV files below are optional and used to pre-populate your competition data. You can always add, edit, or remove events, members, preferences, and conflicts after creation using the edit pages. Empty rows and extra columns are ignored.

What is it?

Pre-populates the available events and groups them by type. You can skip this and add events later using the Edit Events page.

Format:

  • No header row.
  • Each row is a group of similar events (event type). Events within a row are separated by commas.
  • Event names should match the names used in your past invitational data.
  • No duplicate event names.
  • Mark 3-person events with "(3)" and build events with "(B)" next to the name.
  • Empty rows are skipped. Extra trailing empty cells are ignored.


Download as CSV: File -> Download -> Comma Separated Values (.csv)

What is it?

Pre-populates event conflict groups (events in the same timeblock that no member can do simultaneously). Requires the Available Events file to be uploaded too. You can also set up conflicts later using the Edit Event Conflicts page.

Format:

  • No header row.
  • Each row is a group of events that conflict with each other (same timeblock).
  • No duplicate event names across all rows.
  • Events not found in the Available Events data are skipped.
  • Empty rows are skipped. Extra trailing empty cells are ignored.


Download as CSV: File -> Download -> Comma Separated Values (.csv)

What is it?

Pre-populates members and their ranked event preferences. You can skip this and add members and preferences later using the Edit Event Preferences page.

Format:

  • No header row.
  • Column A is the member name. No duplicate member names.
  • Mark seniors with "(S)" next to their name.
  • Columns B, C, D, ... are the member's ranked event preferences (most preferred first). These are optional — a member with no listed events will simply have no preferences.
  • Events not found in the Available Events data are skipped.
  • Member names should match the names used in your past invitational data. Only letters are kept; uppercase/lowercase does not matter.
  • Empty rows are skipped. Rows can have different numbers of columns.


Download as CSV: File -> Download -> Comma Separated Values (.csv)

What is it?

Pre-populates partner preferences (two members who want to be on the same event together). Requires the Member Event Preferences file to be uploaded too. You can also set up partner preferences later using the Edit Partner Preferences page.

Format:

  • No header row.
  • Column A is the first member, column B is the second member, column C is the event.
  • Each row needs at least member 1 and member 2. Rows missing an event or referencing unknown members/events are skipped.
  • Member and event names should match those used in the other data. Only letters are kept; uppercase/lowercase does not matter.
  • Empty rows are skipped. Rows can have different numbers of columns.


Download as CSV: File -> Download -> Comma Separated Values (.csv)
