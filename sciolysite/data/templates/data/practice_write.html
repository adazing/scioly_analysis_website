What is it?

This file specifies a practice test for a particular event that members took and how many points each member got.

Step 1: Make data. Requirements:

  • NO HEADER
  • All the member names should be listed in the A column. Only the member's names should be shown as strings, and only roman alphabet letters will be taken into account. Uppercase/lowercase does not matter. Make sure that the way you named the member is the same as in all the other competitions.
  • Points are required for each member and must state the points (MUST be a float) that the member got on the practice test.
  • Colors/formatting does not matter.

Step 2: Download CSV data.

(If you are using Google Sheets)

File -> Download -> Comma Separated Values (.csv)
